

# What is a database?

A collection of data that can be stored, modified, and retrieved. It stores data from several applications in a structured format. This makes storage, modification, and retrieval easy and efficient.

As an example, when a login page asks you for your credentials, the server will refer the SQL database to retrieve the stored secret, if correct, login is allowed.

All user interaction is stored within the database.

## What language do most databases use?

**SQL or, Structured Query Language**

### What is SQL Injection?

SQL injection is a vulnerability within a web application that allows an attacker to retrieve, modify, or view information they were not meant to see.
